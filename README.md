# Portfolio — Mahamoud Diabate

Portfolio personnel en HTML/CSS/JavaScript vanilla, sans framework.

**Pourquoi sans framework ?** Une page vitrine statique n'a pas besoin d'un runtime de 40 ko. Vanilla donne un chargement quasi instantané, zéro dépendance à maintenir et un déploiement GitHub Pages direct. Mes projets applicatifs utilisent React et Next.js là où l'état et la complexité le justifient.

**En ligne :** https://mahamoud-diabate.github.io/portfolio/
